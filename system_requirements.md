# System Requirements

- **OS**: Ubuntu Linux (20.04 LTS or 22.04 LTS recommended)
- **CPU**: 4+ cores (recommended for concurrent evaluations)
- **RAM**: 8 GB+ (16 GB recommended)
- **Storage**: 20 GB+ SSD
- **Software**: Node.js 22.5+ (for the built-in `node:sqlite` module), npm, git
- **Network**: Allow inbound HTTP/HTTPS traffic to the Web Interface port. Allow outbound access to target LLM endpoints and provider APIs (OpenAI, Anthropic, etc.).
